# LiLa＋VTT＋归一化 GAWM 评测下降：latent 监督分析

2026-09-29。分析对象：最终 step765120，Clean 38.6%（193/500）；对照旧双相机 grid 版本81.4%（407/500）。本次只做离线推理干预、梯度和接口探针，没有改训练权重，也没有启动新训练。

## 判断

latent 监督与新视觉前端的组合是高优先级嫌疑，已有同样本目标漂移及真实未来替换收益的直接证据。但尚未完成“只改监督目标”的受控重训，不能声称已证明42.8个百分点下降全部由 latent loss 引起。旧版也使用类似 MSE/余弦公式，问题更准确地说是监督空间、梯度路径和新视觉表示之间的兼容性。

## 1. 退化具有普遍性，种子差异不是充分解释

- 50个任务中49个退化、1个持平、没有提升；8个任务为0/10。
- 仅比较有效种子序列完全相同的35任务：旧版294/350=84.0%，新版140/350=40.0%，仍下降44个百分点。并非所有仿真随机因素都因此得到控制，但15任务的种子序列差异无法解释主要差距。
- 例如 blocks_ranking_rgb：10/10→0/10；place_object_scale：10/10→0/10；blocks_ranking_size：8/10→0/10。均为同种子任务。
- 成败在回合顺序上没有出现统一的后段失效；每个回合索引的跨任务成功数分别为18/18/20/17/19/20/20/19/22/20。

## 2. 同一批输入上的目标空间漂移已实测

使用固定32个真实示范锚点，同一图像分别通过各 checkpoint 的在线视觉前端，比较得到的 latent。两版每视角均64 tokens、384维，但旧版为固定空间网格，新版为可学习 queries；各模型的跨checkpoint相似度在自身空间内计算。

| 第12→16 epoch，step573840→765120 | 旧 grid 版 | 新 LiLa＋VTT 版 |
| --- | ---: | ---: |
| 同一样本 latent 平均 cosine | 0.9914 | 0.7642 |
| 同一样本 latent MSE | 0.01743 | 0.47372 |
| 固定样本预测/copy误差比值 | 0.4706→0.4573 | 0.5189→0.5266 |

新版从 step371000 到最终的同样本 cosine 为0.3424。归一化后目标仍会改变方向和几何；这次确认的不只是随机训练窗口之间样本组成的差异。跨模型原始 MSE 不作为绝对质量比较；上表相似度也只证明表示变化，不能单独证明变化有害。

## 3. 动作确实使用未来分支，但不能将其全部解释为未来推理

固定400个训练示范锚点：50任务×Clean/Randomized各1轨迹×4时刻。两版使用完全相同的样本；非独立验证集，以下数值不是闭环成功率。

| 动作头输入干预 | 旧版动作L1 | 新版动作L1 |
| --- | ---: | ---: |
| 正常预测未来 | 0.008505 | 0.010940 |
| 替换为真实未来 latent | 0.008401 | 0.009362 |
| 未来改为复制当前 | 0.038475 | 0.038163 |
| 跨样本打乱预测未来 | 0.080888 | 0.060098 |
| 只保留当前视觉 | 0.042464 | 0.042601 |
| 错配任务条件 | 0.039486 | 0.042051 |

- 真实未来替换让新版动作误差降低14.4%，旧版仅1.2%；新版预测未来与动作所需信息存在更明显差距。
- 即使新版使用真实未来，动作误差仍高于旧版正常预测；因此预测误差本身不是充分解释。
- VTT/文本条件主要通过世界模型未来分支进入ACT。删除或复制未来同时移除了这条任务信息通道，故不能把全部误差增加归因于丧失未来预测能力。替换真实未来、打乱或删除tokens也可能属于分布外干预，不是严格最优上界。

## 4. 当前梯度探针不支持“latent loss大，所以压垮了动作梯度”

在最终 checkpoint 上取8个batch（每批4样本），eval模式、关闭dropout和统计更新，分别求动作L1与加权latent+cosine的梯度。

- 新版视觉 adapter 的未来监督梯度为None，动作梯度非零。未来目标由动作/正则塑造，世界模型只能追踪它。
- 世界模型参数上的WM/动作梯度norm比值中位数：新版2.16，旧版3.05。
- 同组梯度平均cosine：新版0.149，旧版0.272；两版均2/8批次为负，显示局部冲突，但没有持续反向的证据。
- 全模型WM/动作梯度norm比值中位数：新版0.320，旧版0.689。
- 按这些单卡探针估算的额外全局裁剪系数中位数：新版0.956，旧版0.813（越低压缩越大）。不能解释为新版受到更严重的全局裁剪压制。

这些不是实际训练时的DDP聚合梯度，也不能推断整个训练历史的冲突情况。

## 5. 接口复核

16个真实HDF5样本，从原始JPEG与末端状态经过实际评测服务端，与训练读取及直接模型推理比较：图像预处理、状态归一化和最终平滑物理动作最大误差均为0。VTT词表完整且checkpoint严格加载；错配任务会明显改变动作，但这不证明VTT任务语义优于旧文本条件。

另检查训练forward与predict_action对同一缓存DINO特征的差异：新版BF16存在batch形状相关数值差（4样本探针max0.003906、mean0.000375，另一4样本max0.011719）；将可训练部分转FP32后同一探针max约6.85e-7、mean约4.25e-8。旧版探针为0。结果与精度/矩阵形状敏感性一致，未发现确定的预处理或状态接口错位；这些微小差异的闭环影响未单独评测，不能完全排除。

## 6. 对 latent loss 定义的具体判断

现有目标为 MSE(pred_z, stopgrad(adapter(DINO(future))))。新版adapter是多层可学习query聚合，旧版是固定空间网格＋较简单投影。逐token MSE假设这些坐标可被稳定预测，但固定query索引并不保证稳定的空间/对象语义，且当前detach使预测监督无法把adapter塑造成更易预测的状态。方向余弦比较整帧展平后的特征变化，并不直接约束物体运动；variance/diversity正则也不固定时间语义。这里有结构性弱点。

不过，同一公式在旧版取得81.4%，且新版同时改变视觉聚合、多层DINO特征和任务条件，不能把“MSE数学形式不成立”当作结论。更合理的假设是：新表征自由度更大，当前移动目标监督与梯度隔离不足以约束它，导致对训练示范的拟合未转化成稳健闭环控制。

## 下一步建议

先按已确认方向构建紧凑latent→特征解码器→冻结DINO patch监督，明确未来loss是否反传至当前adapter；监督参照不能再经过在线可训练投影。做同一视觉前端/VTT/ACT下只改变预测监督的对照，再单独验证时间平滑，避免同时叠加SAM/Mamba。若检验“辅助loss权重过大”，另从同一checkpoint做固定数据、相同优化设置的短训权重对照，不能用删未来分支替代这个实验。
