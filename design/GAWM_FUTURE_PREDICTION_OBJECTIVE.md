### 已确定的方向

1. 保留可训练的 adapter/bridge 和紧凑 latent；世界模型预测未来 latent，ACT 使用该表示生成动作。
2. 增加特征解码器，把主要未来预测监督移到冻结 DINO 的未来空间 patch 特征。目标分支不经过在线可训练 adapter、融合层或投影；DINO 固定权重、eval 模式，目标预处理确定且一致。
3. 单独约束 latent 的时间平滑性：减少无意义抖动，同时保留接触、抓取、释放等真实变化。adapter、DINO 监督或 LayerNorm 本身都不保证平滑。
4. 保留尺度约束并验证信息保留。固定 DINO 监督解决目标参照漂移，归一化解决尺度，时间正则解决连续性；三者不能混为一谈。

建议数据流：

    x_t = frozen_DINO(I_t)
    z_t = adapter(x_t)
    pred_z[t+h] = world_model(z_t, VTT)
    pred_x[t+h] = feature_decoder(pred_z[t+h])
    L_future = distance(pred_x[t+h], stopgrad(frozen_DINO(I[t+h])))
    ACT(current_z, pred_z, state) -> actions

特征解码器恢复 DINO 特征，不是 RGB；推理时 ACT 直接使用紧凑 latent，可省略解码器。不要把“未来 adapter 输出 detach”误记为“固定教师”。仅保留现有目标再加归一化或平滑，不满足此次改版要求。

### 下一轮实现时需要验证的选择

- 先保留 +16/+32 的固定未来预测语义。事件关键帧选择、RGB 生成和动作条件世界模型不在此次已确定修改范围内。
- 特征监督优先尝试逐 patch cosine loss；DINO 层、解码器结构和 loss 权重通过对照确定。单位向量 MSE 与 cosine 基本等价，不应重复叠加后声称增加独立信息。
- 平滑优先尝试弱权重、稳健的二阶时间差分；一阶差分趋零可能压制正常运动。仅用 0/16/32 三点不能验证逐帧平滑，需要短连续片段或较密辅助时间采样；存在可靠时间戳时按实际间隔计算，不把删帧后的索引当作均匀物理时间。
- 事件附近可放宽平滑，权重不能由模型自由降为零。具体事件信号和阈值尚未确定，不应声称已有事件标签。
- 明确检查梯度路径：冻结教师不反传，预测损失经解码器更新预测器。是否解除当前世界模型输入 detach，让 adapter 也受未来监督影响，需要明确选择并验证。
- 若保留旧 adapter-space latent loss 或变化方向 loss，只能作为经过论证的辅助项，不能让它继续充当主要漂移监督目标。

### 验证标准

- 固定留出轨迹和 DINO 教师，分预测时刻评估，并对比复制当前帧、均值基线。
- 同时监控 latent 尺度、时间一/二阶差分、跨状态方差和信息保留。现有正则在单帧 token 维度计算，不能排除整条轨迹输出相同 token 组的时间塌缩。
- 区分单次预测内部平滑和连续观测下重新预测的稳定性；平滑不能以明显事件响应延迟为代价。
- 比较无平滑／有平滑，以及 ACT 删除或打乱未来 tokens 的效果，最终检查闭环成功率。监督空间变化后的 raw loss 不与旧值直接比较。

## 与“未来关键帧预测”的关系

当前实现是任务条件下的未来视觉表征预测，符合未来预测的方向；尚不是可重建未来图像、自动选择事件关键帧或按候选动作推演的完整模型。

| 能力 | 当前实现 |
| --- | --- |
| 输入 | 当前帧两路视觉 token＋任务 VTT；VTT 来自训练示范 |
| 预测目标时刻 | 当前记录帧之后 +16、+32 帧，不等于秒数，也不是事件关键帧标签 |
| 输出 | 两组未来视觉 token，各 128×384；无 RGB 图像解码器 |
| 状态输入 | 16D 状态传给 ACT；当前世界模型预测器不直接接收状态 |
| 动作条件 | 当前世界模型不接收候选动作，不能用来比较不同候选动作的未来结果 |
| ACT 的视觉输入 | 当前 token＋预测未来 token，未直接输入真实未来图像 |

## loss 的实际含义

令 `z_t` 是视觉适配器和 GAWM bridge 的输出；修复版在 bridge 后、加入相机编码前使用无可训练增益的 LayerNorm。

世界模型同时预测两个未来，不是先预测近未来再递推远未来：

`pred_z[t+h] = stopgrad(z[t]) + delta_scale * predictor(stopgrad(z[t]), VTT)[h]`

- **latent MSE**：预测与 `stopgrad(z[t+h])` 的逐元素平方误差，按有效未来帧/视角/特征维度平均。
- **方向余弦 loss**：比较预测变化 `pred_z[t+h]-z[t]` 与真实变化 `z[t+h]-z[t]` 的方向，权重 0.1。当前实现先把每个时刻的 token 和特征维度展平，再计算余弦；不是逐物体或逐空间点的匹配。
- **总 loss**：动作 L1＋1.0×latent MSE＋0.1×方向余弦＋0.02×视觉 diversity＋0.02×视觉 variance。
- `delta_scale` 为目标差分 RMS 的移动统计，缩放预测残差；原 MSE 不因此成为方差归一的损失。本次新增 `latent_mse_over_delta_scale_sq` 只用于监控，不改变优化目标。

作为辅助动作学习的未来特征回归，这个定义有依据。归一化后，其输出尺度有明确约束，比原来无归一化的组合合理。

## 为什么低 loss 仍不能证明预测了未来关键帧

1. **监督目标还会变化**：DINO 冻结，但融合/适配器/bridge 继续训练；detach 只切断本次反传，不能让目标跨训练步保持固定。固定 LayerNorm 控制幅值，不固定特征语义。
2. **没有要求保留所有未来画面信息**：世界模型预测压缩 token，目标表征可以偏向动作相关信息。它不是像素或固定空间 patch 的完整重建任务。
3. **确定性回归可能平均多种未来**：相同当前图像和任务可能对应不同动作分支，模型没有动作条件，也没有显式未来分布建模。
4. **未来分支可能未被充分使用**：ACT 同时看到当前 token；如果当前帧足够，它可以减少对预测未来的依赖。需要消融验证。
5. **已知余弦 mask 限制仍在**：完全无效的未来时刻会以零余弦参与平均。该旧世界模型行为本次保持不变，不能用这个常量解释先前视觉尺度增长。

## 更强目标的下一步设计

若核心目标是可靠预测未来关键视觉内容，优先考虑为未来预测增加固定语义的监督：预测冻结 DINO 的未来 patch 特征（使用独立预测读出层对齐维度/空间位置），或使用缓慢更新的 EMA 视觉教师。它们能减少在线目标持续变化；仍需单独验证，而非仅替换一个 loss 名称。

若“关键帧”指抓取接触、抬起、放置等事件，应先定义这些事件的目标帧/采样规则；当前 +16/+32 帧采样不会自动获得事件语义。若要求看到未来 RGB，应增加图像解码或对应的固定视觉 latent 解码器。

建议验证：

- 固定、未参与训练的轨迹和固定教师，分 +16/+32 时刻统计预测误差及余弦；分别对比复制当前特征、均值未来等基线。
- 重点看夹爪、物体接触及目标区域，而不只看背景主导的整体相似度。
- 对 ACT 做删除/打乱预测未来 token 的消融，并比较使用真实未来特征的诊断上界，检查策略是否实际利用预测信息。
- 用闭环成功率评估动作收益；预测精度和控制收益是两个需分别检查的结论。

本次用户已授权的工作是停止旧 run、补充 bridge 归一化、启动新 run 并监控稳定性。因此本轮保留原世界模型结构和损失，仅修复接口尺度并增加监控；没有默默引入新的教师、动作条件或图像解码器。
