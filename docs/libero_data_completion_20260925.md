## 来源覆盖与纠正

LIBERO-90 本地元数据中的 73 是唯一语言描述数量，不是场景任务数量；官方 90 个场景任务对应 74 个唯一语言描述。此前由 73 推断缺失 17 个任务不成立。实际缺失哪些场景/示范，需要对照原始 HDF5 动作序列确定。

LIBERO-10 根据已有 `raw_alignment_audit.json` 中 500 条原始示范的动作签名，与本次实际读取结果匹配：

| 覆盖情况 | 数量 |
| --- | ---: |
| 原始动作序列已存在（379 基础 + 21 replay） | 400 |
| 原始动作序列缺失 | 100 |
| 上述 100 条中，已有同训练初始状态的 teacher 替代轨迹 | 89 |
| 原始序列和 teacher 替代轨迹均未覆盖的训练初始状态 | 11 |

因此，现有 110 条补充轨迹由 21 条 replay 和 89 条 teacher 组成。Teacher 示范不等于原始动作序列，不能把 489 个初始状态覆盖误写为 489 条原始示范已恢复。这里使用历史原始数据签名，仍需新下载的固定版本 HDF5 复核。失败示范需排查重放/转换原因，不能只为补齐数量加入失败轨迹。
