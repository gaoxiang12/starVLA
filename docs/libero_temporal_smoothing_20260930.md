# LIBERO 时间平滑诊断与训练对照

本轮先检查已完成的固定 DINO 模型，再验证弱时间约束是否同时改善表示稳定性与闭环成功率。当前诊断没有发现新 latent 比 DINO 更抖的证据；连续预测的相对波动仍接近输入表示，而单次预测内部已经较平滑。因此本轮约束相邻观测下的表示与重新预测，不加强原来的粗未来轨迹平滑。

## 无平滑模型的实测

固定四套件40个任务，每任务一段最长96帧的连续训练示范，覆盖可用的夹爪切换附近。80k、160k使用完全相同的图像和时间段。它们不是留出验证集。指标先按每个token做单位向量归一化，定义相对波动为二阶差分RMS除以一阶差分RMS，再对40段等权平均。这个指标没有统一的合格阈值，也不能把真实快速运动直接判为噪声。

| 表示 | 相对波动 |
|---|---:|
| 冻结 DINO patch | 1.602 |
| 80k 当前 latent | 1.583 |
| 80k 近未来预测跨观测变化 | 1.580 |
| 160k 当前 latent | 1.564 |
| 160k 近未来预测跨观测变化 | 1.560 |

80k模型单次预测三时刻的二阶差分RMS为0.165，同时间间隔的真实adapter输出为0.471，说明继续压平预测内部轨迹未必是合适的首选。连续重预测同一目标时刻的RMS差异约0.338；新信息到来本身可以引起合理修正，该量不是纯噪声。

160k略平滑，但闭环成功率从80k的95.5%下降到92.75%，进一步说明平滑度不是成功率的替代指标。DINO和latent维度不同，不直接比较跨空间的原始RMS或方差。

数据中的时间戳对应20Hz存储序列。no-op删除后原始仿真间隔不一定完整保留，不能声称这些导数反映严格的原始物理加速度。

## 本轮时间约束

沿用LiLa视觉、VTT、冻结DINO patch目标、ACT和所有原损失。训练额外读取前一帧和后一帧，保持主任务的当前、+4、+8帧完全不变。

- 约束前一帧、当前帧、后一帧的紧凑latent，以及从这三个观测分别预测同一相对未来时距的latent。
- 按记录时间间隔计算速度变化，以0.05秒为参考缩放，使用beta=0.1的Huber损失。恒速运动为零损失，不要求一阶变化趋零。
- 当前表示与预测表示各占一半，总权重0.1。原有0/.2/.4秒的粗未来轨迹平滑保持权重0。
- 轨迹首尾缺失邻帧时整组三点不计损失；无效时间间隔拒绝使用。
- 当前帧前后两帧范围内出现夹爪命令切换，权重降为0.25，保持非零且不可学习。这只是事件代理，不是接触或抓取成功标签。
- 邻帧仅用于训练辅助分支，ACT输入与推理接口保持当前观测及其预测未来。测试已验证邻帧改变不改变动作前向输出。
- 保留固定DINO监督、当前帧重建、尺度约束和token正则；同时检查跨时间方差，避免通过输出常量获得较低平滑损失。

8个真实训练batch、80k检查点eval模式的梯度抽查中，权重0.1的附加梯度在视觉adapter与预测器上相对原目标的范数比中位数3.85%，最大5.14%。这只是确定初始弱权重的诊断，不代表整个训练过程的DDP梯度比例。

## 训练和评测安排

从头训练到80k，全局batch160、seed42、原数据与VTT不变。沿用原C调度前缀：77,028步切换阶段，cosine名义周期256,760步，不能把80k误改成压缩调度。新增分支没有可训练参数，初始化结构不变；额外编码和attention计算会改变算力及数值路径。

先做32步真实多卡短训和40任务各1回合仿真接口检查，通过后启动正式训练。保留40k和80k，完成80k后分别：

1. 四套件、每任务10个官方初始状态、seed7，共400回合；40k对无平滑40k，80k对无平滑80k，80k为主要比较点。
2. 在完全相同40段示范上复测当前latent、跨观测未来预测的相对波动与方差、DINO误差、同目标时刻重预测差异。
3. 比较逐帧重算的首个连续动作的二阶变化、夹爪符号切换和事件附近时差。这是离线示范状态上的诊断，不是仿真执行动作轨迹，也不等同于执行8步动作块时的延迟。

评价必须同时报告平滑性和成功率，不能只挑更平滑的检查点。夹爪事件匹配使用同方向、正负8个存储帧窗口；漏匹配和切换次数另报，避免只看匹配成功的事件。单训练种子、每任务10条仍是快速对照。
